# Seria – planer treningowy

Aplikacja webowa do planowania treningu siłowego: plan na cały tydzień, partie na dziś,
sugestia następnego treningu, rozgrzewka, 187 ćwiczeń ze zdjęciami i dziennik ciężarów.

Działa w przeglądarce telefonu. Na iPhonie: otwórz stronę w Safari → Udostępnij →
„Do ekranu początkowego”. Po pierwszym uruchomieniu działa też bez internetu.

Dane (treningi, ciężary, plan) zapisują się w przeglądarce telefonu. Kopię zrobisz w zakładce
**Więcej → Kopiuj kopię danych**.

Zdjęcia ćwiczeń: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domena publiczna).
